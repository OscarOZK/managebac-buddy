🧪 ManageBac-Buddy

使用说明

作业、课表、成绩、Teams 学习待办，加一个能直接问的 AI · 适配 macOS 26 液态玻璃

✦这一版带来了什么

v3.5 做了三件你每天都会碰到的手感变化——动画、玻璃、登录。（另有一件你多半感觉不到、却让它在别人电脑上也能跑起来的事：浏览器与 Python 现在都内置在 App 里。）

动起来的每一处，都是想清楚过的

悬停、按下、选中、翻页、数字滚动……每一类动作各有自己的时长与曲线，不再各自为政地写死同一个 0.2 秒。改一个档位，整块界面的节奏一起变；页面切换现在认方向，往后翻和往前翻各走各自那一侧。设置里的「减弱动效」也不再是摆设——它是真的总闸。

玻璃要透光，也要挡光

卡片、侧栏、按钮与菜单栏面板的玻璃质感重新拆成了三层：最外一圈只折射、不上色，中间一层是毛玻璃加主题底色，最外沿压一道高光——于是它像真的玻璃那样有了厚度。玻璃强度跟着主题走，也能随时在设置里调。

登录，回到「不必被注意」的样子

冷启动不再谎报「已登录」；连不上的时候，界面说的是为什么没连上，而不是一句会让你去改密码的「请检查账号密码」。引导页也改成要你填完整的学校邮箱。登录本该按下去就进去，然后被你忘掉。

（首次打开时那段一帧帧写出来的 MB BUDDY 与彩虹 hello，现在只演一次；退出重进直接落在看板上。）

1一个 App，两个入口

  • ManageBac-Buddy.app —— 唯一的 App。双击打开完整看板窗口。
  • 菜单栏图标 —— 同一个 App 常驻菜单栏，点图标看今天的作业与倒计时；关掉主窗口它也还在（真退出走菜单栏面板里的「退出」或 ⌘+Q）。
  • 以前是「看板 + 菜单栏」两个 App，已合并成一个：一个进程、一份数据、一份通知——不会再有同一条消息弹两遍、或者旧成绩反复冒出来的情况。

首次打开若提示「无法验证开发者」，右键 App →「打开」→ 再点「打开」即可（本机自己签的名，不是从商店下载的）。

2五个分区在讲什么

  • 待办 —— 顶部是「距离最近一件事还有多久」的大倒计时（上课 / 下课 / 晚自习），下面四格是待完成、24 小时内、本周内、已出分；再往下按「越急越靠前」排的作业卡，卡左边的色条就是紧急度。
  • Teams —— 见第 3 节。
  • 课程 —— 今天的课表 + 一整周的课表网格，按学科配色，换行就是一天。课表不随 App 一起发出去：它是只属于你的东西，每台电脑要自己导一次（启用希悦后点「立即同步」，或把 timetable.json 放进数据目录）。没导之前这一页会告诉你两条路，见第 6 节。
  • 成绩 —— GPA 总览环 + 各科明细，点任意一行看该科全部作业。
  • 灵析 AI —— 见第 4 节。看板里的对话助手，作业、成绩、课表都能直接问它。
  • 设置 —— 见第 5 节，四个账号统一在「设置 → 账号管理」里管。

快捷键：⌘+1~5 切分区、⌘+R 立即刷新、Esc 关掉登录窗。

3灵析 AI：不用 API Key 的对话助手

灵析 AI 是看板里的对话助手：把作业、成绩、课表、或者一张截图丢进去问它就行。它走的是你自己 DeepSeek 账号的网页登录态——不需要注册开发者、不需要填 API Key、不额外收费，用的是你本来就能用的那个额度。

怎么连

进灵析 AI 分区（没登录时会自动把登录页摊在窗口上），或者点「设置 → 账号管理 → DeepSeek → 去登录」。在上面用手机号 / 邮箱 / 微信任意一种登录即可，登完点左上角的「我已登录好了」。这台电脑会记住登录，以后打开就能直接用。

怎么用

  • 直接打字问，⏎ 发送、⇧⏎ 换行。空着的时候页面上有三条起手式可以直接点。
  • 带文件：点输入框左边的回形针选文件 / 图片，或直接把图拖进剪贴板——开着「剪贴板带图」时它会自动带上最新那张（永远跟最新一张同步，不会赖着上一张）。
  • 固定附件：点顶栏的「固定附件」，把某个文件钉住，以后每次进这一页都自动带上它（比如你的课表图）。再点一次取消。
  • 换主题：它的配色、圆角、玻璃全部跟着看板设置走，切主题 / 改圆角 / 调密度时它一起变。
💡
想问「网站上的聊天记录」？点顶栏「原站」会打开真正的 DeepSeek 网页，历史记录都在那边；这边的「清空」只清空看板这一页的显示，不动网站上的记录。

登录没成功？按这个顺序试

  1. 点「我已经登录好了」——页面登录完成后需要你确认一下。
  2. 没反应就点「重连」，把登录页整个重新加载一遍。重载不会掉登录（登录状态记在这台电脑上），所以放心点。
  3. 再不行就点「打开登录页」重登一次，或者把 App 退掉重开。
⚠️
只要登录页本身能正常输入，通道就是通的——问题基本都出在「还没登完就去看结果」。另外 DeepSeek 偶尔会要求人机验证，那一屏必须在页面里手动过掉。

4Teams 板块：连一次微软账号

把 Microsoft Teams / Outlook 里和学习有关的东西集中到一处：微软任务里的作业、邮件里提到的事（自动转成待办）、聊天里点名提到你的消息、以及未来两周的日程。所有内容只读，绝不回写你的微软账号。

怎么连

点「连接微软账号」→ 弹出浏览器 → 选你在学校的账号（会列出这台电脑上登录过的微软账号）→ 同意即完成。连一次就够了，之后凭据会自动续期，不用重复登录。

📶
连接过程会在卡片上实时显示进度（正在试哪条通道、第几条）。这是正常的：程序会按顺序尝试多个微软官方客户端，第一条走通的就停下来。
⚠️
如果浏览器里出现「需要管理员批准」，说明学校租户不接受该客户端的权限申请。程序会自动改用下一个客户端重试；若所有通道都被挡住，就需要学校 IT 管理员批准——这属于租户策略，无法在本地绕过。

它申请了哪些权限

只申请「普通用户自己能同意」的最小集合：读你自己的邮件、日程、Microsoft To Do 任务、Teams 聊天。带 .All 的（读别人数据）和仅管理员可授予的权限一律不申请。

某条数据源没连上怎么办

程序会按实际拿到的权限决定拉哪些源，缺权限的自动跳过，不报错、不刷屏。例如 Planner 需要管理员权限，若未获批就只显示 Microsoft To Do 里的任务，其余功能不受影响。

怎么断开

卡片上有「断开连接」，本地令牌立刻清除，不会影响你的微软账号设置。

5设置能改什么

设置页顶部有一条实时预览，改任何一项都会立刻反映到预览、菜单栏角标和整个看板里。

分组可调项
账号管理四个账号一处管：ManageBac、Microsoft Teams、希悦、灵析 AI（DeepSeek）各自显示「已连接 / 未连接」、连的是哪个账号、什么时候校验过，能单独登录 / 退出 / 重连。位置就在「主题」下面——见第 6 节
外观与主题主题（跟随系统 / 浅色 / 深色）、界面密度、圆角、液态玻璃强度、字号缩放、减弱动效、降低透明度
强调色与学科配色强调色 6 选 1 或自己取色；10 个学科每个都能单独改色；另有莫兰迪 / 鲜艳 / 沉稳三套预设一键换
通知总开关、通知哪些来源（待办到期 / Teams 新任务 / 邮件 / 日程 / 成绩 / English Corner / 每日汇总）、提前几小时提醒、学科白名单、免打扰时段、提示音；通知图标按「学科 × 事项种类」两个维度区分——学科决定底色与主符号，事项种类决定右下角小圆角标和标题最前面的 emoji，所以一眼就能分出「哪一科、哪类事」
待办紧急度阈值红 / 黄 / 蓝三档的小时数用滑块调（三条滑块的轨道颜色就是卡片上三档标签的颜色），右侧始终显示当前数值；还能设「不显示的关键词」
刷新与启动自动刷新间隔、开机自动启动、菜单栏显示哪几档、逾期是否计入、待办显示条数上限
小看板显示哪些区块（大计时 / 待办 / 课堂 / 成绩 / EC / 快速设置）、面板宽度与高度、待办条数、成绩每行几个；主题默认跟随大看板，也可以关掉跟随、让小看板单独选深浅色与配色
作息起床 / 晚自习起止时间，以及「打开看板时停在哪一页」（默认「待办」，切页不会把它改掉）
配置文件设置存在 ~/.mbboard/settings.json；「恢复默认」保留使用者档案，「恢复新手导览」连档案一起清空并回到第一屏重新引导
💡
改错了想恢复？设置页最下面有「恢复默认」（保留你的名字与年级）。想彻底从头来一遍，用「恢复新手导览」——它会清空全部设置与档案，然后立刻带你重新走一遍引导。所有设置都存在本机，不会上传。

6四个账号统一管：账号管理

这个看板一共要连 4 个账号，全部集中在 设置 →「主题」下面的「账号管理」 里。每张卡都会告诉你：连没连上、连的是哪个账号、上次是什么时候校验的，并且能单独登录 / 退出 / 重连。

账号它管什么怎么连
ManageBac作业、截止时间、成绩、课表账号 + 密码。勾了「记住」就存进 macOS 钥匙串，只在本机、只有你能读；不勾就只在这一次登录里用一下
Microsoft Teams从任务、邮件、聊天里自动挑出学习待办点「打开浏览器登录」→ 在弹出来的浏览器里选学校账号 → 同意。这边会自动识别
希悦课表（比 ManageBac 的更好看），一周同步一次就够点「打开希悦登录」→ 在窗口里登录 → 回来点「同步课表」
DeepSeek（灵析 AI）灵析 AI 的对话能力点「去登录」→ 登录页盖在窗口上 → 登完收起

顶部两个按钮：「全部检查」把四个账号一起查一遍；「重连」是在 ManageBac / Teams / 希悦 一起变红时用的——那通常是本机服务没起来，点一下会把它重新拉起来再查一遍。

💡
四个账号都可以先跳过、以后再用。引导里每一步都能「跳过这一步」，设置页里随时能补——跳过不影响其它功能，用到哪一块它会提示你。

7数据从哪来、隐私怎么算

  • 程序用你登录的会话去读 ManageBac 的作业、课表与成绩，只读，不会替你提交任何东西。课表内容也不在 App 里：它从你自己电脑上的 timetable.json 读，别人的电脑上没有这份文件。
  • Teams 板块走微软官方接口（Microsoft Graph），同样是只读：只读你自己的邮件、日程、任务与聊天，不会修改、不会代发任何内容。
  • 希悦课表走本机的浏览器会话读取，同样只读。
  • ManageBac 的密码（若你选择保存）存在 macOS 钥匙串里，只有当前用户能读；微软那边只存一个可随时吊销的授权令牌。
  • 看板自己不传任何数据：没有本项目的服务器，作业 / 成绩 / 课表一律只落在这台电脑上（~/Library/Application Support/ManageBac-Buddy/，在访达里按 ⌘⇧G 粘贴这个路径就能进去）。
  • 但灵析 AI 是例外，这一点要说清楚：你发给它的问题、以及随消息带上的文件 / 截图，会直接发送给 DeepSeek（就像你在网页版里聊天一样），由 DeepSeek 按其条款处理。所以不要把不想外传的东西丢给灵析 AI；其余四个分区的内容不会经过它。登录态（cookie）只存在这台电脑的网页存储里，随时可以在「账号管理」里退出清除。
  • 断网时用上次抓到的数据继续显示，并标注「更新于 xx:xx」。

8遇到问题

现象怎么办
双击提示「无法验证开发者」右键 →「打开」→「打开」。只需一次。
一直显示「登录已失效」看板里重新登录一次 ManageBac；若学校有二次验证，登录窗里改用「用浏览器登录」。
灵析 AI 一直没反应 / 显示未登录按顺序试：① 点「我已经登录好了」；② 点「重连」（重新加载登录页，不会掉登录）；③ 点「打开登录页」重登一次，或把 App 退掉重开。只要登录页里能正常输入，通道就是通的。
灵析 AI 问完一直空着DeepSeek 偶尔会弹人机验证 —— 点「原站」把真实网页摊开，在页面上过掉验证再回来。
账号管理里 ManageBac / Teams / 希悦 一起变红本机服务没起来。点右上角「重连」把它重新拉起来再查一遍；还不行就把 App 退掉重开。
Teams 里出现「需要管理员批准」程序会自动换通道重试；若都失败，需要学校 IT 批准该客户端，属于租户策略。
菜单栏图标不见了菜单栏太长被挤掉了：退出一些常驻图标，或把 App 重新打开一次（它是同一个 App 的图标，不再有单独的菜单栏 App）。
通知里冒出旧的成绩 / 同一条消息两份已修：现在只有一个进程发通知，同一条消息只播一次，超过 4 天的新成绩、3 天前的 Teams 任务一律只记账不弹窗；同类一次超过 2 条会合并成一条。想立刻清空通知中心，点右侧的「清空已投递通知」。
数据看起来是旧的⌘+R 或点右上角刷新；也可以把自动刷新间隔调短。
