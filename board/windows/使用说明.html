🪟 Windows 版 · 桌面常驻

ManageBac-Buddy

把 ManageBac 的作业截止、课表与成绩，做成一个常驻在系统托盘旁边的桌面看板。双击即用，不需要浏览器、不需要装 Python。

1怎么打开

双击文件夹里的 ManageBac-Buddy.exe。

  • 第一次打开会弹出登录窗：输入一次 ManageBac 账号密码即可。想省事就勾上「在本机保存账号密码」，以后掉登录会自动重登。
  • 如果学校账号有验证码或二次验证，点「用浏览器登录」，在弹出的窗口里自己登，登完关掉即可。
  • 登录成功后，程序常驻系统托盘（右下角小图标）。关掉窗口不会退出，点托盘图标随时再打开。
💡
建议右键 ManageBac-Buddy.exe →「发送到」→「桌面快捷方式」，以后从桌面一键开。

2托盘图标在看什么

托盘图标就是「桌面版的菜单栏」：图标本身就是状态。

角标样式样子含义
彩色圆点 右列依次是红 / 黄 / 蓝三档各有几项待办。一眼看出轻重缓急。
数字角标 红圈里的数字 = 红+黄+蓝合计（最多显示到 9，超过一律显示 9）。
仅图标 — 不带角标，最大程度安静。

鼠标悬停在托盘图标上，会显示精确数字（例如「红 3 项 · 黄 2 项 · 蓝 1 项」）。
右键托盘图标是一份快捷菜单：打开看板、立即刷新、切主题、调角标样式、在浏览器打开 ManageBac、打开设置文件位置、退出。

窗口最小化时，任务栏图标上也会出现一个红色数字角标，这是 Windows 的原生习惯。

3看板里的四个分区

  • 待办 —— 顶部是「距离最近一件事还有多久」的大倒计时（上课 / 下课 / 晚自习），下面四格是待完成、24 小时内、本周内、已出分；再往下按「越急越靠前」排的作业卡，卡左边的色条就是紧急度。
  • 课程 —— 今天的课表 + 一整周的课表网格，按学科配色，换行就是一天。
  • 成绩 —— GPA 总览环 + 各科明细，点任意一行看该科全部作业。
  • 设置 —— 下面一整节都在讲它。

快捷键：Ctrl+1~4 切分区、Ctrl+R 立即刷新、Esc 关掉登录窗。顶部搜索框可以按学科或作业名过滤。

4Teams 板块：连一次微软账号

侧边栏的 Teams 会把 Microsoft Teams / Outlook 里和学习有关的东西集中到一处：微软任务里的作业、邮件里提到的事（自动转成待办）、聊天里点名提到你的消息、以及未来两周的日程。所有内容只读，绝不回写你的微软账号。

怎么连

点「连接微软账号」→ 弹出浏览器 → 选你在学校的账号（会列出这台电脑上登录过的微软账号）→ 同意即完成。连一次就够了，之后凭据会自动续期，不用重复登录。

⚠️
如果浏览器里出现「需要管理员批准」，说明学校租户不接受该应用的权限申请。程序已经内置了多条通道：它会自动改用下一个客户端重试（进度会实时显示在卡片上）。若所有通道都被挡住，就需要学校 IT 管理员批准——这属于租户策略，无法在本地绕过。

它申请了哪些权限

只申请「普通用户自己能同意」的最小集合：读你自己的邮件、日程、Microsoft To Do 任务、Teams 聊天。带 .All 的（读别人数据）和仅管理员可授予的权限一律不申请。

哪一条数据源没连上怎么办

程序会按实际拿到的权限决定拉哪些源，缺权限的自动跳过，不会报错、不会刷屏。例如 Planner 需要管理员权限，若未获批就只显示 Microsoft To Do 里的任务，其余功能不受影响。

💡
想断开？卡片右下角有「断开连接」，本地令牌立刻清除，不会影响你的微软账号设置。

5设置能改什么

设置页顶部有一条实时预览，改任何一项都会立刻反映在上面的预览、托盘角标和整个看板里。

分组可调项
外观与主题 主题（跟随系统 / 浅色 / 深色）、界面密度（紧凑 / 舒适 / 宽松）、圆角（直角 / 标准 / 圆润）、液态玻璃强度、字号缩放、减弱动效、降低透明度
强调色与学科配色 强调色 6 选 1 或自己取色；8 个学科每个都能单独改色；另有莫兰迪 / 鲜艳 / 沉稳三套预设一键换
待办紧急度阈值 红 / 黄 / 蓝三档的小时数用滑块调（默认 26 / 50 / 74 小时），上方色带实时预览分档；还能设「不显示的关键词」，把含这些字的作业过滤掉
刷新与启动 自动刷新间隔（1–60 分）、开机自动启动、托盘上显示哪几档、逾期是否计入、待办显示条数上限
💡
改错了想恢复？设置页最下面有「恢复默认」。学科配色等所有设置都存在本机，不会上传到任何地方。

6数据从哪来、隐私怎么算

  • 程序自带的浏览器内核会按你设定的间隔，用你登录的会话去读 ManageBac 的作业、课表与成绩，只读，不会替你提交任何东西。
  • Teams 板块走微软官方接口（Microsoft Graph），同样是只读：只读你自己的邮件、日程、任务与聊天，不会修改、不会代发任何内容。
  • 登录状态由 Windows 自己保管，关掉再开还是登着的。
  • 如果要保存密码，用的是 Windows 自带的加密（DPAPI），只有当前这台电脑的这个账户能解开。
  • 所有数据都只落在这台电脑上，没有任何服务器、没有上传。
  • 断网时用上次抓到的数据继续显示，会在角标旁标注「更新于 xx:xx」。

7遇到问题

现象怎么办
托盘图标不出现 Windows 11 会把不常用的图标收进「^」折叠区，点开把本程序拖到任务栏上即可常驻。也可以在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里打开。
一直显示「登录已失效」 在登录窗里重登一次；若学校有二次验证，改用「用浏览器登录」。也可以右键托盘图标 → 立即刷新重试。
数据不更新 右键托盘 → 立即刷新。若还不行，检查是否断网，或在设置里把自动刷新间隔调小。
想彻底退出 右键托盘图标 → 退出。只点窗口右上角的 × 只是收起窗口。
想搬走 / 备份 整个文件夹拷到别的 Windows 电脑就能用（建议在新电脑上重新登录一次）。
⚠️
这是便携版程序，请保持文件夹内所有文件在一起，不要把 exe 单独拖出来，否则会打不开。
