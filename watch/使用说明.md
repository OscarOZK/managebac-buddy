# ManageBac Watch App — 工程说明

一个 watch-only 的 watchOS SwiftUI App（没有 iPhone 配套 App，表上独立运行）＋
**12 个表盘小组件**。数据来自本机看板服务 `http://127.0.0.1:8765/api/data`，
所以**只在模拟器里连得通**（手表真机上的 127.0.0.1 指的是手表自己）。

界面为 watchOS 26 的**原生液态玻璃**（`.glassEffect`），
秒级倒计时只驱动该刷新的那张卡，派生数据按「分钟 + 数据版本」记忆化 —— 见下面「架构」。

## 目录结构

```

  xcshareddata/xcschemes/ManageBacWatch.xcscheme

  WatchTheme.swift     配色 / 原生液态玻璃卡片 / 表盘尺寸自适应
  WatchVM.swift        面板状态：秒级时钟 + 派生数据记忆化（架构中枢）
  WatchCards.swift     各类卡片（大计时卡、现在横条、待办条、课程行、成绩块、GPA 行）

  WatchRules.swift     课表、学科配色、紧急度分档、成绩折算

  Info.plist           WKApplication=YES / WKWatchOnly=YES

ManageBacWatchWidgets/                     ← 小组件 extension（独立进程）

  MBWidgetData.swift   取数、时间线、会自己走秒的倒计时、公共小件
```

## 怎么跑

方式一（Xcode）：双击 `ManageBacWatch.xcodeproj`，选 Apple Watch 模拟器，按 ⌘R。

方式二（命令行）：

```bash
cd "ManageBacWatch工程"
bash build.sh              # 编译（含小组件扩展）+ 安装 + 启动
bash build.sh --open       # 顺便打开模拟器窗口
```

前提：本机看板服务在跑（打开桌面上的「ManageBac-Buddy」App 即可）。

## 界面里的液态玻璃

- 所有卡片都是 `WatchCard`（`WatchTheme.swift`）：默认走 watchOS 26 的 `.glassEffect`，
  可点的（逾期展开 / GPA 展开 / 立即刷新）传 `interactive: true`，按下去有真实高光回应。
- 相邻卡片用 `GlassEffectContainer`（`CardStack`）编成一组，系统按批次渲染，滚动不掉帧。
- 两个自动降级：**屏幕变暗**（Always-On、抬腕前）和**出图自检**时退回 `ultraThinMaterial`
  （玻璃在变暗时反而会闪，且离屏渲染画不出来）。
- 想整体关掉玻璃看对照：启动时加 `MBW_NO_GLASS=1`。

## 架构：为什么流畅

| 原来的问题 | 现在的做法 |
| --- | --- |
| 面板每 1 秒整体重评 body，等于每秒把所有待办的 ISO 时间解析、GPA 汇总、整日课表重算一遍 | 派生数据交给 `WatchVM`，按「分钟 + 服务端数据版本 + 条目数」做指纹，指纹不变直接复用 |
| 秒级时钟推着整屏（几十张卡）一起刷 | 秒级只给 `WatchTick` 订阅的**大计时卡**与「现在」横条；面板本身 10 秒一跳 |
| 变暗后秒表还在跑，费电还闪 | `isLuminanceReduced` 时停表，大计时卡改用粗粒度时间 |
| 小表盘（40/41mm）用 46mm 的尺寸，文案被挤掉 | `WatchMetrics` 按真实屏宽算缩放（0.86–1.0），内边距/字号/卡片高一起收 |

## 12 个小组件

### 单一主题（8 个）

| 小组件 | 显示什么 | 支持的形态 |
| --- | --- | --- |
| 待办清单 | 最急的 3 条待办（科目 + 作业名 + 剩余时间） | 圆形 / 圆角 / 行内 |
| 待办紧急度 | 74 小时内到期的红黄蓝各几项 | 圆形 / 圆角 / 行内 |
| 课堂倒计时 | 上课时距下课、课间距上课、晚自习 | 圆形 / 圆角 / 角标 / 行内 |
| 今日课表 | 正在上的那节 + 接下来两节 | 圆形 / 圆角 / 行内 |
| 最新成绩 | 最近出分的作业（科目 / 作业名 / 等级 / 分数） | 圆形 / 圆角 / 行内 |
| 总均分 GPA | 各科总均分 + 满分 4 分折算 | 圆形 / 圆角 / 角标 / 行内 |
| 今日概览 | 今天几节课 + 在上的那节 + 最急待办 | 圆形 / 圆角 / 行内 |
| 下一节课 | 下节课时间 / 教室 / 老师；上课时变下课倒计时 | 圆形 / 圆角 / 行内 |

### 综合（4 个）：一屏同时看到「课 + 待办 + 成绩」

| 小组件 | 三行分别是什么 | 支持的形态 |
| --- | --- | --- |
| **学习总览** ★ | 课 + 距下课/上课倒计时 ｜ 最急待办 ｜ 最新成绩 | 圆形 / 圆角 / 角标 / 行内 |
| 课堂速览 | 课 + 倒计时 ｜ 接下来两节（隔天会标「周一」）｜ 最急待办 | 圆形 / 圆角 / 行内 |
| 成绩速览 | 最新两条成绩 ｜ 距下课/上课 + 待办数 | 圆形 / 圆角 / 行内 |
| 紧迫速览 | 课 + 倒计时 ｜ 最急待办 ｜ 红黄蓝计数 + 最新等级 | 圆形 / 圆角 / 角标 / 行内 |

> 综合小组件的倒计时用的是 `Text(timerInterval:)`：**由系统逐秒刷新，不需要新的时间线条目**。
> 用静态字符串的话要等下一次刷新（5 分钟）才变，表盘上就是个「冻住的数字」。
> 超过 6 小时的倒计时（例如「距周一上课」）退回静态短写，不值得让系统逐秒渲染。

**怎么加**（模拟器与真机操作一样）
- 智能叠放：按数码表冠回到表盘 → 向上滚/上滑进入智能叠放 → 滚到底「…」→ 添加小组件 → 找 ManageBac
- 表盘复杂功能：长按表盘 → 编辑 → 选到某个复杂功能槽位 → 在列表里找 ManageBac

**离线表现**：课表类内容用的是内置课表，电脑上的服务没开也照常显示；
依赖网络的部分（待办 / 成绩 / GPA）会显示「未连上电脑上的看板服务」，不会崩。

## 调试开关（命令行启动时生效）

| 变量 | 作用 |
| --- | --- |
| `MBW_DUMP=1` | 把派生数据（待办排序 / 课堂 / 最新成绩 / GPA）与 VM 重算次数打到系统日志 |
| `MBW_AT=10:20` | 把「现在」定在这一时刻，用来核对上课 / 课间 / 现在横条 |
| `MBW_SCROLL=class` | 启动后自动滚到指定分区（class / latest / gpa / bottom） |
| `MBW_GPA=1` | GPA 分区直接展开 |
| `MBW_NO_GLASS=1` | 关掉液态玻璃，退回 ultraThinMaterial（对照用） |

App 日志：`xcrun simctl spawn <设备UDID> log show --last 2m --predicate 'subsystem == "cn.oscar.ManageBacWatch"'`

小组件日志（排查「小组件不刷新 / 连不上」）：
`xcrun simctl spawn <设备UDID> log show --last 5m --predicate 'subsystem == "cn.oscar.ManageBacWatch.widgets"'`

## 小组件版式自检

```bash
bash render/run.sh                    # 用真实数据渲染一张（12 行 × 3 种形态）
bash render/run.sh --offline          # 模拟「服务没开」
bash render/run.sh --at 09:45         # 把「现在」定在课间
```

原理：小组件视图只依赖一个跨平台的 `MBFamily` 枚举（`MBFamily.swift`）；
小组件运行时由 `MBFamilyInjector` 从系统给的 `widgetFamily` 翻译过来，
Mac 上的自检工具直接注入想核对的形态 —— 于是同一套视图能在 Mac 上按表盘尺寸渲染。

> 注意：`WidgetFamily.accessoryCircular / accessoryRectangular / accessoryInline /
> accessoryCorner` 在 macOS 上被标为 unavailable，这也是要绕一层的原因。
> 另外自检把「现在」定住时，倒计时会退回静态文字（系统计时器按真实时钟走，硬用它只会画 0:00）。

## 工程要点

- `objectVersion = 77` + `PBXFileSystemSynchronizedRootGroup`：源码目录自动收录，
  加/删 `.swift` 文件不用改工程文件（本次新增的 `WatchVM/WatchCards/MBWidgetMix` 都没动 pbxproj）。
- 两个 `Info.plist` 都通过 `PBXFileSystemSynchronizedBuildFileExceptionSet` 从资源里排除，
  否则会报 `Multiple commands produce .../Info.plist`。
- App 用 `PBXCopyFilesBuildPhase`（`dstSubfolderSpec = 13`，PlugIns）把 `.appex` 嵌进去，
  并用 `PBXTargetDependency` 保证先编扩展；扩展的 bundle id 是 `cn.oscar.ManageBacWatch.widgets`。
- 扩展的 `Info.plist` 里 `CFBundlePackageType = XPC!`、
  `NSExtensionPointIdentifier = com.apple.widgetkit-extension`，另带本地网络 ATS 豁免。
- `WATCHOS_DEPLOYMENT_TARGET = 26.0`，最低 watchOS 26（液态玻璃也从这一版开始）。
- 验证小组件真的注册成功：
  `xcrun simctl spawn <设备> log show --last 20m --predicate 'process == "chronod"' | grep -oE "mb\.[a-z]+" | sort | uniq -c`
  —— 12 个 kind 都会出现。
